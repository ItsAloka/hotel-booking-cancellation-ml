# Data layout

`raw/hotel_bookings.csv` is the unchanged 119,390-row Hotel Booking Demand mirror used in the project. See [source record](raw/SOURCE.md) for the Kaggle link, actual download URL, fingerprint and provenance limitations.

`processed/v2/` is generated by notebooks 01 and 02. It contains the cleaned audit table, 20-feature model-only train/test CSVs, split/source/group membership, inner folds, rejected and flagged records, and a manifest with versions/fingerprints. Generated CSVs are ignored by Git and can be rebuilt.

The older `processed/hotel_bookings_clean.csv`, `processed/train.csv` and `processed/test.csv` remain historical v1 for provenance. They are not the revised model inputs. Always use `scripts/foundation.py:load_split` for v2 training.
